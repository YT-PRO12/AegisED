# AegisED Python service

Synthetic adult priority model plus operational knowledge retrieval. See the root README and `docs/MODEL_CARD.md` for intended use and measured results.

```bash
python -m pip install -r requirements.txt
python train.py
python evaluate_retrieval.py
python -m pytest -q
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

The browser accesses this service through Express. When `ML_SERVICE_TOKEN` is set, send it as `X-Service-Token` to `/predict`, `/model` and `/knowledge`. `/health` is a process/model readiness endpoint. The token must be identical on Express and Python. Environment variables are read from the process, not automatically from a `.env` file.

`POST /predict` accepts age and complete vital values; the supported synthetic age range is 18â€“89. `GET /model` returns evaluation metadata. `POST /knowledge` accepts `{question}` and returns explicitly identified retrieval, generation or no-context mode. Optional Ollama variables are described in `docs/KNOWLEDGE.md`.

The trusted local `.joblib` artifact is generated by `train.py`; never load arbitrary user-supplied pickle files. The included portable archive contains the completed model so it need not be retrained immediately. Git ignores generated binary/data/index files; a fresh Git checkout trains them with the commands above.
